原型说明（评审要点）

      
    
        
  • 菜单位置：新增一级菜单「工具」，子菜单「设备指令查询」，置于「测试管理」之下；由新权限项 device_tools.view_device_command 控制显示。
    • 
        
  • API Key 只做密码框输入，不做持久化、不进日志、不写入历史记录；请求由后端代理携带转发。
    • 
        
  • 服务地址由后端固定配置（示例为测试环境），前端只读展示，避免代理被利用访问任意内网地址（SSRF）。
    • 
        
  • 设备类型固定为 EMS（取自产品实例表），查询指令目录由后端配置提供，当前为占位指令，待网关文档提供后替换；参数表单按目录定义动态渲染。
    • 
        
  • 请求预览中的 Body 默认按 { action, params } 组装，可按网关实际协议调整；支持手动改写后再发送。
    • 
        
  • 响应区展示状态码、耗时、大小、响应体与响应头；会话内保留最近请求记录，便于对比排查。
